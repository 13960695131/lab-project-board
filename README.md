# 实验室项目展示板

> 一个用来练习 Vue 3 的小项目：把实验室里的项目用卡片形式展示出来，可以新增、删除、搜索，数据存在浏览器里。

## 1. 项目名称
实验室项目展示板

## 2. 项目简介
这是一个新人练习项目，目的是边做边学 Vue 3 + Vite 的基本用法。
没有后端、没有数据库，所有数据都保存在浏览器（localStorage）里，刷新页面也不会丢。
整个项目是和 AI 助手**一个阶段一个小功能**地搭起来的，方便理解每一步在做什么。

## 3. 已实现功能
- 展示项目列表（每个项目是一张卡片，包含名称、简介、成员、技术栈、状态、GitHub 地址）
- 新增项目（点击按钮弹出表单填写）
- 删除项目（删除前会弹窗确认，避免误删）
- 按项目名称搜索（输入关键字实时过滤；支持子串匹配，例如搜"巡检"能找到"智能巡检机器人"）
- 数据自动保存在浏览器（localStorage），刷新或重开页面数据还在
- 项目状态：`进行中` / `已完成` / `暂停`，不同状态用不同颜色的标签区分

## 4. 使用技术
- 前端框架：**Vue 3**（`<script setup>` 写法）
- 构建工具：**Vite**
- 样式：原生 CSS（没有用任何 UI 框架）
- 数据存储：浏览器 **localStorage**（无后端、无数据库）

## 5. 如何安装
需要先在电脑上安装 **Node.js**（建议 18 或以上版本）。
然后在项目目录下运行：

```bash
npm install
```

## 6. 如何运行
启动开发服务器（改代码会自动刷新页面）：

```bash
npm run dev
```

启动后打开终端里显示的地址，一般是 `http://localhost:5173/`。

其他命令：
- `npm run build`：打包生成静态文件，输出到 `dist/`
- `npm run preview`：本地预览打包后的结果

## 8. 我通过这个项目学习到了什么
（下面是这次练习的真实收获，可以改成你自己的话）
- **Vue 基础**：组件（`.vue` 文件）、模板语法（`{{ }}`、`v-for`、`v-if`）、事件绑定（`@click`）
- **响应式数据**：用 `ref` / `reactive` 让"数据一变，页面自动跟着变"
- **计算属性 `computed`**：像"搜索过滤"这种"根据别的数据算出来"的结果，不用手动更新
- **监听器 `watch`**：数据一变就去存 `localStorage`
- **`v-model`**：表单输入和数据的双向绑定，不用自己读输入框的值
- **浏览器 `localStorage`**：在没有后端的情况下也能保存数据
- **跑起一个前端项目**：用 Vite 启动，以及 `npm run dev` 和 `npm run build` 的区别
- **一点点 Git**：`init` / `status` / `add` / `commit`，把代码存进版本库

这是一个练习项目，代码追求"能看懂、够用就好"，没有做复杂的架构设计。
